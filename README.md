# One-Line Office Joke Laugh-Off

One original one-line joke about office life. `main.ts` writes the joke to `entry.txt`, enforcing the gates — non-empty, at most 200 characters, exactly one line and exactly one sentence ending in a single period — then reads the file back and verifies the bytes match.

> "HR said the open-plan office encourages collaboration, which is how I learned Dave's entire divorce settlement in surround sound."

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-suzy-one-line-office-joke-laugh-off-f574ac73-out node main.ts
```
